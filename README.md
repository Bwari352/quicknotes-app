
# QuickNotes App

QuickNotes is a simple, responsive note-taking web application built using HTML, CSS, and JavaScript. It allows users to create and organise notes into Personal, Work, and Study categories, search through notes, and delete notes when they are no longer needed. Notes are stored in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work, or Study categories.
- Display each note with its category and creation date.
- Give each category a different coloured left border.
- Delete individual notes.
- Validate notes to prevent empty entries and notes longer than 200 characters.
- Search notes instantly without case sensitivity.
- Display the total number of saved notes.
- Save and load notes using localStorage.
- Responsive layout for desktop and mobile screens.

## How to Run the Project Locally

1. Download or clone this repository to your computer.
2. Open the `quicknotes-app` folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code to run the application.

No additional packages or installations are required.
